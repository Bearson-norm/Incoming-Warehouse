Ini merupakan sistem penghubung antara mesin timbangan dengan VPS dengan memanfaatkan web socket dengan node js (terserah dengan express atau dengan nestJS). Di sistem ini ada beberapa fitur yang dihadirkan diantaranya ada sebagai berikut :
1. Fitur koneksi ke mesin dari COM yang configurable, ada juga pilihan autoconfigure untuk memudahkan konfigurasi, buatkan handling ini yang tidak redundan
2. Fitur koneksi ke VPS dengan menginput alamat domain atau alamat IP yang terintegrasi dengan API endpoint sesuai dengan yang sudah ditentukan dari folder Dashboard sebagai handler di sisi VPS, buatkan handling yang robust seperti fungsi reconnection dll. Dan buatkan agar performa yang dirender dari instrumen penimbangan -> gateway -> dashboard bergerak dengan cepat
Adapun buatkan agar sistem ini bisa digunakan standalone, tidak apa-apa jika diperlukan setup di device developmentnya namun dia bisa jalan di device lainnya setelah dilakukan setup. Buatkan yang robust dan kompatibel untuk semua OS
