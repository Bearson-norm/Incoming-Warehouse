1. Pengenalan

Incoming Warehouse membantu tim gudang mencatat berat barang masuk dengan timbangan digital. Anda memindai nomor LPN di palet, menunggu angka stabil, lalu menyimpan hasil ke sistem gudang (Odoo) atau menyimpannya sementara di komputer stasiun jika Odoo belum siap.

Alur besar (tanpa istilah teknis)

Timbangan fisik mengirim angka ke komputer stasiun → layar menampilkan berat hidup → Anda konfirmasi → sistem menyimpan dan (jika metode Odoo) memberi tahu gudang pusat. Data juga bisa disalin ke server cloud agar supervisor melihat banyak stasiun sekaligus.

5. Incoming — langkah & tombol

  1. Pilih timbangan — Harus sama dengan meja Anda. Cloud offline → panggil IT.
  2. Pilih Odoo / Internal — Tidak bisa diubah setelah Konfirmasi.
  3. Scan LPN — Metode Internal: pilih vendor, kemasan, kode RM.
  4. Konfirmasi — Form kiri terkunci; panel kanan tampil.
  5. Tunggu badge Stabil (hijau) — jangan konfirmasi saat kuning.
  6. Mulai Penimbangan — Setelah ini Reset tidak tersedia.
  7. Konfirmasi Penimbangan / Simpan Berat — tombol hijau.
  8. Kartu hasil — PASS hijau / FAIL merah / lokal krem; Cetak atau Kirim ke Odoo.

Tracing LPN lintas perangkat — Cari tracking · Ekspor bukti audit (JSON/CSV/SHA-256)
SiapaSupervisor & admin IT.
KapanCek koneksi pusat, lacak LPN antar PC, kelola nama timbangan.
  1. Kartu hijau = terhubung; merah = operator mungkin tidak lihat daftar timbangan
  2. Antrean belum tersinkron → Ulangi sinkronisasi
  3. Tracing LPN → siapa, stasiun mana, kapan
  4. Admin: Kelola Timbangan (nama di dropdown Incoming)

Operator biasa tidak perlu buka halaman ini setiap palet.
