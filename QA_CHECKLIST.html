Incoming Warehouse QA Checklist

Regression checklist for LPN weighing, serial Gateway, authenticated dashboard, PostgreSQL, and Odoo WMS integration. Results and notes are saved in this browser.

Release rule: all P0 cases must pass. Any failed P0 case blocks release. P1 failures require an accepted defect and workaround.
Worst outcomes to actively try to cause
Correct weight attached to the wrong LPN Race two operators, two tabs, LPN replacement, delayed WebSocket frames, and Gateway switching. This is the highest operational risk because the number can look valid while belonging to another package.
Odoo accepts weight but local history says nothing happened Kill PostgreSQL after Odoo replies, exhaust DB connections, or terminate the API during persistence. Recovery must expose the Odoo log ID and prevent a blind retry.
One physical weigh becomes two receipts Double-click, retry after timeout, use two tabs, and restart the API mid-request. The same session must resolve to one confirmed outcome.
Old or unstable scale data is accepted as current Disconnect the cable after a stable reading, change the load, reconnect after minutes, and replay buffered packets. Confirmation must require a fresh stable server snapshot.
Scale unit error causes a 1,000× inventory error Send 1,234 g as kg, uppercase/lowercase units, unknown units, and values near rounding boundaries. Unknown units must fail closed.
Warehouse keeps operating against the wrong environment Point Electron at staging Postgres or staging Odoo, rotate one key only, and use copied config files. The active targets must be visible and production secrets must not silently fall back.
History and dashboard totals disagree during audit Use pagination, timezone boundaries, duplicate sessions, failed Odoo results, and imported SQLite rows. All reports must count the same confirmed business event.
Unauthorized LAN user controls or observes the scale Attempt anonymous Socket.IO access, call port 4124 remotely, reuse expired tokens, and test weak/default keys. No live weight or serial configuration may leak.
